# Hinweis für Claude Code

Die Betriebsanleitung dieses Projekts steht in **[`AGENTS.md`](AGENTS.md)**.
Lies sie, bevor du buchst oder Code änderst — sie ist bewusst dort, damit
Claude Code, OpenAI Codex, Gemini CLI und die übrigen Coding-Agenten
dieselbe Anleitung benutzen.

Das Wichtigste in fünf Zeilen:

1. Du richtest ein, buchst, passt die Anwendung an und meldest zurück —
   **freigeben tut ein Mensch.**
2. Beträge sind ganze Cent, niemals Gleitkomma.
3. Mandantendaten gehören in `mandant.json`, nie in den Code.
4. `bh pruefen` und `bh abgabe` haben recht, bis du das Gegenteil **belegt**
   hast. Regeln werden nicht gelockert, damit eine Beanstandung verschwindet.
5. Was dir gefehlt hat, wird ein Issue in `RichardS83/llm-buchhaltung` —
   ohne die echten Daten, an denen es auffiel.
